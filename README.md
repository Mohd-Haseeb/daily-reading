# Daily Reading

A curated daily reading list (AI engineering, databases, distributed systems, runtimes, architecture, cloud, security, healthcare tech), generated by a scheduled Claude task and served as a static site via GitHub Pages.

## Layout
- `index.html` — the site (no build step, no dependencies)
- `data/index.json` — `{"days":[{"date":"YYYY-MM-DD","areas":["..."]}]}`
- `data/entries/YYYY-MM-DD.json` — one file per day:
  `{"date":"YYYY-MM-DD","focus":"<title of focus item>","items":[{"title","url","source","area","why","summary","exercise"}]}`

Read/done state is stored in your browser's localStorage.
